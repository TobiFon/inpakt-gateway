# Impakt Gateway e.V.

Official web platform for **Impakt Gateway e.V.**, a Germany-registered non-profit association (_eingetragener Verein_) facilitating bilateral cooperation, education, youth innovation, and sustainable development initiatives between Africa and Germany.

- **Legal Entity:** Impakt Gateway e.V.
- **Seat:** Berlin, Deutschland
- **Registration Court:** Amtsgericht Charlottenburg (VR 42655 B)
- **Official Domain:** [https://impaktgateway.de](https://impaktgateway.de)
